# Article-local methodology extensions

The reusable Prompt-Literate Workflow core lives under:

```text
../prompt-literate-workflow/
```

Article-local extensions live under:

```text
./
```

Extensions do not redefine the Prompt-Literate Workflow core.

`primes-example/` is an additive article-local specialization for Knuth's prime-number task. Prime-specific markers and validators remain local to that extension.

Future project-specific extensions must live with their consuming projects, not inside this article companion.
