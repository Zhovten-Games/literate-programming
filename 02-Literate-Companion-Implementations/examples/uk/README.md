# Набір companion-документів (Українська)

Цей каталог містить сім companion-варіантів для огляду literate programming:

1. 01-cweb
2. 02-noweb-like
3. 03-org-babel
4. 04-quarto
5. 05-jupyter
6. 06-rmarkdown
7. 07-prompt-literate (приклад Prompt-Literate Workflow)

CWEB і noweb-like найближчі до класичного literate programming.
Quarto, Jupyter і R Markdown належать до гілки executable documents.
`07-prompt-literate` позначено як приклад Prompt-Literate Workflow (експериментальний метод) із властивостями, відмінними від детермінованих 01–06.
Prompt-Literate Workflow — експериментальний метод обмеження LLM-assisted генерації через human-authored plan, chunk contracts, bounded prompts, review, tests і TRACE.


Детермінований/відтворюваний набір: `01`–`06`.
`07-prompt-literate` — експериментальний граничний варіант, який за замовчуванням не містить згенерованого виводу.
