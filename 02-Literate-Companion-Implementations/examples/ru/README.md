# Набор companion-документов (Русский)

Этот каталог содержит семь companion-вариантов для обзора по literate programming:

1. 01-cweb
2. 02-noweb-like
3. 03-org-babel
4. 04-quarto
5. 05-jupyter
6. 06-rmarkdown
7. 07-prompt-literate (пример Prompt-Literate Workflow)

CWEB и noweb-like наиболее близки к классическому literate programming.
Quarto, Jupyter и R Markdown относятся к ветви executable documents.
`07-prompt-literate` помечен как пример Prompt-Literate Workflow (экспериментальный метод) и не эквивалентен детерминированным 01–06.
Prompt-Literate Workflow — экспериментальный метод ограничения LLM-assisted генерации через human-authored plan, chunk contracts, bounded prompts, review, tests и TRACE.


Детерминированный/воспроизводимый набор: `01`–`06`.
`07-prompt-literate` — экспериментальный граничный вариант и по умолчанию не содержит сгенерированного вывода.
