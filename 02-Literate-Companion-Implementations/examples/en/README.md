# Companion Set (English)

This directory contains seven companions for the literate programming review:

1. 01-cweb
2. 02-noweb-like
3. 03-org-babel
4. 04-quarto
5. 05-jupyter
6. 06-rmarkdown
7. 07-prompt-literate (example of Prompt-Literate Workflow: experimental method)

CWEB and noweb-like are the closest variants to classical literate programming.
Quarto, Jupyter, and R Markdown are executable-document descendants.
`07-prompt-literate` is an example of Prompt-Literate Workflow: an experimental method for constraining LLM-assisted generation through a human-authored plan, chunk contracts, bounded prompts, review, tests, and TRACE.


Deterministic/reproducible set: `01`–`06`.
`07-prompt-literate` keeps generated output optional by default and treats prompt output as non-deterministic while validation remains controlled.
