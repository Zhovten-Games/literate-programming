# Суправаджальны набор: беларуская версія

Сем прыкладаў да агляду літаратурнага праграмавання:

1. `01-cweb` — поўны гістарычны tangle/weave.
2. `02-noweb-like` — палегчаны C++-працэс з іменаванымі фрагментамі.
3. `03-org-babel` — Org-mode, tangling, выкананне і экспарт.
4. `04-quarto` — выканальны дакумент.
5. `05-jupyter` — інтэрактыўны нататнік.
6. `06-rmarkdown` — узнаўляльная справаздача.
7. `07-prompt-literate` — эксперыментальны Prompt-Literate Workflow.

CWEB і noweb найбліжэйшыя да класічнага літаратурнага праграмавання. Quarto, Jupyter і R Markdown развіваюць выканальныя дакументы. Варыянт `07` абмяжоўвае LLM-генерацыю чалавечым планам, кантрактамі, промптамі, аглядам, тэстамі і TRACE. Дэтэрмінаваны набор складаюць `01`–`06`; у `07` генерацыя неабавязковая, яе вынік недэтэрмінаваны, а валідацыя кантралюецца.
