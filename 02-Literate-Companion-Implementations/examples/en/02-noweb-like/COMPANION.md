# Companion

This companion shows a practical noweb-like workflow for one literate source file: `primes.nw`.

## Source model and compact pipeline

noweb-like source:

- `primes.nw` (canonical literate source)

Machine branch:

- `primes.nw -> notangle -Rprogram -> primes.cpp -> g++ -> primes -> output.txt`

Readable/document layer in this simplified companion:

- the readable documentation layer is the source file itself: `primes.nw`.
- there is no mandatory second generated PDF/HTML document in this example.

`primes.cpp` is intentionally committed as a demonstration of tangled output and must match:

```bash
notangle -Rprogram primes.nw > /tmp/primes-from-noweb.cpp
diff -u primes.cpp /tmp/primes-from-noweb.cpp
```

Why this matters: this is the cleaner practical core of literate programming without the full CWEB/TeX ritual. It keeps named chunks, explanatory ordering, a root chunk, and explicit tangling into machine-oriented source; it removes CWEB-specific marker conventions, mandatory `cweave`, TeX macro requirements, and PDF generation as a required second stage.

## Machine branch (compiler-oriented)

```bash
notangle -Rprogram primes.nw > /tmp/primes-from-noweb.cpp
diff -u primes.cpp /tmp/primes-from-noweb.cpp
g++ -std=c++17 -Wall -Wextra -pedantic primes.cpp -o primes
./primes > output.txt
grep "Page 1" output.txt && grep "Page 5" output.txt && grep "7919" output.txt
```

Expected output markers include:

- `The First 1000 Prime Numbers --- Page 1`
- `The First 1000 Prime Numbers --- Page 5`
- `      6571      6997      7499      7919`

## Optional readable/document branch

Classic noweb also provides `noweave`, so separate readable output is possible:

- `primes.nw -> noweave -> TeX/LaTeX/HTML-style readable output`

This companion intentionally demonstrates the lighter tangle-only path, where `primes.nw` itself remains the human-readable document.

## Markers and chunk syntax (noweb)

- `<<program>>=` defines a named chunk named `program`.
- `<<name>>` references another named chunk.
- `@` terminates the current chunk.
- `notangle -Rprogram` chooses `program` as the root chunk.
- `notangle` expands referenced chunks and generates ordinary C++.
- The C++ compiler never sees noweb markers; it only sees generated `primes.cpp`.

## Why not just comments?

Ordinary comments:

- explanation attached to code.
- source remains mostly code-first.

noweb-like:

- code organized inside an explanatory source.
- named chunks can be introduced in the order of human understanding.
- `notangle` assembles those chunks into machine-oriented order.

Short formula:

- Ordinary comments: explanation attached to code.
- noweb-like: code organized inside an explanatory source, then extracted for the machine.

This variant is often easier to keep alive in modern projects because it has lower ceremony than CWEB. Named chunks resemble patterns familiar from Markdown code blocks, documentation-driven examples, notebook cells, and executable documents. It is useful for small demonstrations, algorithm notes, teaching material, and focused reference implementations.

Balanced note: CWEB is historically closer to Knuth and stronger as a full tangle/weave system; noweb-like is lighter and better suited as the main C++ reboot example in this companion set.

## Installation notes (tested Debian/Ubuntu/WSL route)

This workflow is primarily Unix-like. On Windows, WSL is the practical route.

Install tools:

```bash
sudo apt update
sudo apt install noweb build-essential
```

Verify:

```bash
command -v notangle
command -v noweave
```

Optional:

```bash
notangle -V
```

`notangle -V` is optional; the important check is that `command -v notangle` returns a path.

`noweb` is not always installed by default. Prefer OS packages where available. The upstream README also recommends package installation because building from source can be old/baroque/brittle.

Line-ending note (Windows/WSL): CRLF in `.nw` may cause visible diff noise or CR artifacts in tangled output. Keep `.nw` and generated `.cpp` with LF endings. If needed:

```bash
sed -i 's/\r$//' primes.nw
notangle -Rprogram primes.nw > primes.cpp
```

This companion directory also uses `.gitattributes` to keep relevant files stable with LF endings.

## Generated files

- `COMPANION.md`  
  Documentation for this companion example. Committed source.
- `primes.nw`  
  Canonical noweb-like literate source. Committed source.
- `primes.cpp`  
  Generated by `notangle -Rprogram primes.nw`. Intentionally committed as a tangled-output example. Do not edit manually unless regenerating/synchronizing the example.
- `primes`  
  Compiled executable. Ignored.
- `output.txt`  
  Local captured program output for smoke-checking. Ignored.

Unlike `01-cweb`, this simplified companion does not produce `primes.tex` or `primes.pdf` as part of its required workflow.
