# primes-example extension

This is an article-local extension for the companion set.

It applies Prompt-Literate Workflow to Knuth's prime-number example. It does not redefine the base methodology; the reusable method remains available through `../../prompt-literate-workflow/` and through the repository-root submodule/scaffold at `prompt-literate-workflow/`.

The extension demonstrates the project-local extension mechanism by adding prime-specific acceptance markers and validation rules on top of the base workflow discipline.
